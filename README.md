# arcade-drivers

This is a repository with a Zephyr-based SSD1306 OLED driver and
rudimentary graphics support for the device. I started development
for this as a part of the Pong project and eventually decided it would
be best to keep it in its own repository.

Integration steps coming soon--it will be recommended to use this as
a submodule for Pong/any future arcade games using the OLED. I'd also like
to try to make this repo more portable to other OLEDs so I'll keep that in
mind as I make changes!
